Configuration: flags, environment variables and config files

A setting comes from, first hit wins: the flag, its CHROME_CDP_* env var,
the project's chrome-cdp.toml or .chrome-cdp.toml (the nearest one walking
up from the current directory), the user's config.toml, then the built-in
default.

User config: $XDG_CONFIG_HOME/chrome-cdp/config.toml, else
~/.config/chrome-cdp/config.toml (macOS: ~/Library/Application
Support/chrome-cdp/config.toml). Keys (unknown keys are errors):

  session = "shop"               --session
  timeout = "20s"                --timeout
  base_url = "http://localhost:3000"   so `goto /login` works
  testid_attribute = "data-test" what testid= reads (data-testid)
  snap_after_action = "diff"     every action adds --snap ("off")
  node_stacks = "on"             open --node-stacks ("off", "localhost")
  snapshot_budget = 4000         snapshot --budget (0 = none)
  source_root = "web"            where places in the page's code are
                                 looked up (src/cart.ts:12); relative to
                                 the file. Default: the nearest directory
                                 up with a project config or .git

The project config's [e2e] section sets up testing (`chrome-cdp init e2e`
writes one). Paths are relative to the file; its base_url is also the
`goto /path` base when the file has no top-level base_url:

  [e2e]
  base_url = "http://localhost:5173"
  tests = ["e2e/scenarios/**/*.cdp"]   scenario files (globs)
  mocks = "e2e/mocks"                  mock sets: <name>.toml
  default_mocks = ["base"]             sets every test gets
  openapi = "api/openapi.yaml"         `mock check` checks mocks against it
  default_backend = "mock"             or a name from [e2e.backends]
  vars = "e2e/vars/mock.toml"          ${var:…} of every backend
  jobs = 4                             tests at once; "auto" = CPUs / 2
  retries = 0
  timeout = "30s"                      per test
  keep_logs = false                    true: passing tests keep their
                                       requests.txt and console.txt too
  artifacts = "e2e/.results"           reports, screenshots, logs
  viewport = "1280x800"

  [e2e.web_server]                     [[e2e.web_server]] for several
  command = "npm run dev -- --port 5173"
  url = "http://localhost:5173"        ready when it answers below 500
  reuse_existing = true                use a server already on url
  timeout = "60s"
  env = { VITE_API_URL = "/api" }
  cwd = "."
  # static = "dist"                    instead of command: chrome-cdp serves
                                       the prebuilt app (no Node needed)

  [e2e.determinism]                    on by default in every test
  freeze_time = "2026-01-01T10:00:00Z"  Date (the default time); or false
  random_seed = 42                     Math.random, …; or false (default 0)
  disable_animations = true            no CSS animations, reduced motion
  locale = "en-US"                     or false for the browser's own
  timezone = "UTC"                     or false

  [e2e.backends.local]                 a real backend: test --backend local
  mode = "real"
  base_url = "http://localhost:8080"
  web_server = { command = "docker compose up", url = "http://localhost:8080" }
  setup = ["./scripts/reset-db.sh"]    teardown = [...] runs after
  vars = "e2e/vars/local.toml"         on top of [e2e]'s vars
  mocks = ["third-party/stripe"]       sets kept on (hybrid mode)
  protected = false                    true: only @safe tests (--allow-writes)
  jobs, timeout, retries, determinism  override [e2e]'s

A web server runs in its own process group with its output in
<artifacts>/web-server.log, and is stopped when the tests end. A static
one serves its folder on url's port (http://localhost:PORT), and answers
paths without a file extension with index.html, for client-side routes.

Environment variables:
  CHROME_CDP_JSON, CHROME_CDP_QUIET, CHROME_CDP_SESSION,
  CHROME_CDP_TIMEOUT, CHROME_CDP_TAB,
  CHROME_CDP_CONTEXT                    the global flags
  CHROME_CDP_LOG                        log filter, e.g. cdp=trace
  CHROME_CDP_SNAP, CHROME_CDP_NO_WAIT_AFTER, CHROME_CDP_STRICT_REFS
  CHROME_CDP_TESTID_ATTRIBUTE           as testid_attribute
  CHROME_CDP_BACKEND                    the backend of test (--backend)
  CHROME_CDP_CHROME                     the Chrome to launch (open --chrome)
  CHROME_CDP_CACHE                      where install puts browsers
  CHROME_CDP_CFT_URL                    a Chrome for Testing index mirror
  CHROME_CDP_AUTO_INSTALL, CHROME_CDP_IDLE_TIMEOUT,
  CHROME_CDP_HTTP_CREDENTIALS, CHROME_CDP_HTTP_CREDENTIALS_ORIGIN,
  CHROME_CDP_CONSOLE_BUFFER, CHROME_CDP_NETWORK_BUFFER,
  CHROME_CDP_NODE_STACKS                open's flags of those names

Examples:
  printf 'base_url = "http://localhost:3000"\n' > chrome-cdp.toml
  chrome-cdp init e2e                   # an [e2e] section and an e2e/ folder
  CHROME_CDP_SESSION=shop chrome-cdp goto /cart
  chrome-cdp open --help                # the launch options
