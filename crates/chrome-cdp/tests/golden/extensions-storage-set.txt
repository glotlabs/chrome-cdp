$ chrome-cdp extensions storage 'chrome-cdp fixture' set '{"theme": "light"}' --area session
exit: 0
--- stdout
set theme in the session storage of chrome-cdp fixture; it holds 1 item

$ chrome-cdp extensions storage 'chrome-cdp fixture' set '{"theme": "light"}' --area session --json
exit: 0
